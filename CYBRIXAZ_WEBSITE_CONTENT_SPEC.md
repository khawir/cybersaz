# 12. Security Testing

Route: `/services/security-testing`

## Hero

### Section label

**OFFENSIVE SECURITY**

### Heading

**THINK LIKE AN ATTACKER. FIX WHAT MATTERS.**

### Copy

CybrixAZ security testing helps organisations identify exploitable weaknesses before they become real-world incidents.

## Black Box External Penetration Testing

Testing is conducted from the perspective of an external attacker with no prior knowledge of internal systems.

Purpose:

- simulate real-world external attack scenarios
- identify externally exploitable vulnerabilities
- evaluate exposed applications and infrastructure
- assess externally accessible attack paths

## Grey Box Internal Penetration Testing

Testing is performed with partial knowledge of the environment.

Purpose:

- combine external testing with limited internal context
- enable more targeted testing
- evaluate vulnerabilities from an authorised internal perspective

## Targeted Penetration Testing

Testing focuses on specific systems, applications, components or high-risk areas. Scope is agreed in advance.

## Code-Assisted Penetration Testing

Testing combines penetration testing with source-level or code-level insight.

Purpose:

- identify vulnerabilities not easily visible through black-box testing
- combine runtime testing with deeper analysis
- improve testing coverage

## Network Infrastructure Penetration Testing

Testing may consider:

- confidentiality
- integrity
- availability
- internal attacker scenarios
- external attacker scenarios
- security controls
- network behaviour

## Web Application Penetration Testing

Testing may include:

- user interfaces
- APIs
- third-party integrations
- plugins
- backend services
- data flows

Testing may be performed using black-box, grey-box or white-box approaches depending on scope.

## Mobile Application Penetration Testing

Platforms:

- iOS
- Android

Testing may include:

- local storage
- application permissions
- communications
- application behaviour
- backend interactions

## AI-Assisted Penetration Testing

- security testing automation
- vulnerability discovery
- attack-surface analysis
- repetitive task automation
- vulnerability prioritisation
- assisted validation

- industrial control systems
